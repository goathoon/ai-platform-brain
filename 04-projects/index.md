# 04 Projects

직접 만들거나 실험할 프로젝트를 관리합니다.

## 후보

- Mini Claude Code: 로컬 파일 검색과 수정 계획을 세우는 작은 coding agent
- Inference Lab: vLLM 또는 Ollama로 latency, throughput, memory를 관찰하는 실험 환경
- Agent Observability: tool call, retry, latency, failure를 추적하는 dashboard
- E2E Strategy Notes: 복잡한 리팩토링을 안전하게 만들기 위한 테스트 전략 정리

## 기록 방식

각 프로젝트는 목표, 설계, 관찰 지표, 실험 결과, 배운 점을 남깁니다.
